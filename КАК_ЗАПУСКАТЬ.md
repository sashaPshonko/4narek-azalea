Боевой код: `4narek-azalea/`. Бинарники одни на все анки: `orch502` (орк) и `bot502` (воркер). Анку задаёшь аргументом / в `orch.json`. Ботов руками не запускаешь — их поднимает орк.

Боевые анки: **502, 503, 504, 506**. Сейчас в `bots/` есть `502b.json`, `503b.json`, `504b.json` (506 — когда будет файл). 507–510 не трогаем.

### Как обновлять файлы на сервере

У фермы **нет нормального git-remote** — код с Mac заливается **rsync** (или один файл через `scp`).  
Цены/предметы Go — **отдельный** репо `4narek-new`, только **git pull** (без scp конфигов).

| Что менял | Как залить | Нужен рестарт |
|---|---|---|
| Код Rust (`crates/…`, `delay.json`) | rsync → `cargo build --release` | да, орки |
| Один `.rs` / `delay.json` | `scp` этого файла → build | да, орки |
| Ники / прокси (`bots/*.json`, `ip.json`, `owner-ip.json`, `clan-owners.json`) | rsync **с ними** или правь на VPS | да, орки (подхватят список) — **только когда сам решил залить** |
| Цены / перцентили / предметы | git в `4narek-new` → на VPS `git pull` | да, **Go** (`4narek-info`), орки не обязательны |

#### A) Весь код фермы (без ников/прокси)

С Mac — **не** затирай боевые ники/IP на сервере:

```bash
sshpass -p '…' rsync -az \
  -e 'ssh -o PreferredAuthentications=password -o PubkeyAuthentication=no' \
  --exclude target --exclude node_modules --exclude .git \
  --exclude listings-state --exclude 'logs/' \
  --exclude 'bots/*.json' --exclude ip.json --exclude owner-ip.json --exclude clan-owners.json \
  /Users/sasha_pshonko/Documents/4narek/4narek-azalea/ \
  root@212.8.229.76:/root/4narek-azalea/
```

Потом на VPS: сборка + рестарт орков (ниже).

#### B) Один файл (быстро)

```bash
# пример: delay.json или item_parse.rs
sshpass -p '…' scp -o PreferredAuthentications=password -o PubkeyAuthentication=no \
  /Users/sasha_pshonko/Documents/4narek/4narek-azalea/crates/bot/delay.json \
  root@212.8.229.76:/root/4narek-azalea/crates/bot/delay.json
```

`delay.json` вшит в бинарь при `cargo build` — без пересборки не подхватится.

#### C) Ники / прокси (осторожно)

Только когда **явно** надо обновить слоты на сервере. Иначе локальные правки остаются локально.

```bash
# целиком ферма включая bots/ip (опасно затереть серверные правки)
sshpass -p '…' rsync -az \
  -e 'ssh -o PreferredAuthentications=password -o PubkeyAuthentication=no' \
  --exclude target --exclude node_modules --exclude .git \
  --exclude listings-state --exclude 'logs/' \
  /Users/sasha_pshonko/Documents/4narek/4narek-azalea/ \
  root@212.8.229.76:/root/4narek-azalea/
```

Или один `bots/504b.json` через `scp` → рестарт орка этой анки.

#### D) Go: предметы / перцентили (`items_config.json`)

На Mac:

```bash
cd /Users/sasha_pshonko/Documents/4narek/4narek-new
# правишь items_config.json
git add items_config.json && git commit -m "…" && git push
```

На VPS:

```bash
cd /root/4narek-new
git pull --ff-only
# JSON читается при старте — пересборка не нужна, только рестарт:
kill $(pgrep -x 4narek-info) 2>/dev/null; sleep 1
nohup ./4narek-info >> go-run.log 2>&1 &
pgrep -a 4narek-info
```

Если менял **код** Go (`.go`) — ещё `go build -o 4narek-info .` перед рестартом.

### Сборка на VPS

```bash
cd /root/4narek-azalea
. "$HOME/.cargo/env"
npm install --omit=dev   # если нет node_modules
cargo build --release -p bot -p orch
```

### Рестарт орков на VPS (после любой смены бинаря / списка ботов)

```bash
cd /root/4narek-azalea
cp -f orch.vps.json orch.json
mkdir -p logs

# важно убить и орков, и ботов (иначе останутся старые bot502-сироты)
pkill -x orch502 || true
pkill -x bot502 || true
# запасной вариант, если имена другие:
pkill -f 'target/release/orch502' || true
pkill -f 'target/release/bot502' || true
sleep 2

nohup ./target/release/orch502 502 >> logs/orch502.log 2>&1 &
nohup ./target/release/orch502 504 >> logs/orch504.log 2>&1 &
# при необходимости:
# nohup ./target/release/orch502 503 >> logs/orch503.log 2>&1 &
```

### Проверить, что живы

```bash
ps aux | grep -E 'orch502|bot502' | grep -v grep
tail -n 50 logs/orch502.log
tail -n 50 logs/orch504.log
# в логе должно быть что-то вроде: Go prices → N позиций в каталоге
```

### Только убить

```bash
pkill -x orch502 || true
pkill -x bot502 || true
```

## Важно

1. **`bot502` сам не стартуй** — орк кормит ему JSON в stdin.
2. Одна копия бинарника на все анки: `./orch502 502`, `./orch502 504`…
3. Нужен файл `bots/{анка}b.json`, иначе орк сразу упадёт.
4. Капча: env по желанию `CAPTCHA_SOLVER_URL=http://127.0.0.1:8799`.
5. Старый Node (`4narek-1.12/*b.mjs`) для боевой фермы **не** используем — только Rust.
6. После `pkill` орка **обязательно** поднимай заново — иначе боты-сироты на старом бинаре.

## Мини-чеклист «поднять с нуля на VPS»

```bash
# 1) Go жив?
pgrep -af 4narek-info

# 2) Солвер жив?
curl -sS http://127.0.0.1:8799/ || true

# 3) Собрать + старт
cd /root/4narek-azalea
. "$HOME/.cargo/env"
cargo build --release -p bot -p orch
cp -f orch.vps.json orch.json
mkdir -p logs
pkill -f 'target/release/orch502' || true
pkill -f 'target/release/bot502' || true
sleep 2
nohup ./target/release/orch502 502 >> logs/orch502.log 2>&1 &
nohup ./target/release/orch502 504 >> logs/orch504.log 2>&1 &
ps aux | grep orch502 | grep -v grep
```
